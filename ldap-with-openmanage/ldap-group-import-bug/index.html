Install Instructions

Section titled “Install Instructions”
  1. Install RHEL
  2. Change hostname 1.hostname freeipa.grant.lan && hostnamectl set-hostname freeipa.grant.lan 2.Change in /etc/hostname 3.Configure DNS to return for this hostname. Double check with dig +short freeipa.grant.lan A && dig +short -x 192.168.1.95
  3. Follow RHEL’s instructions 1.I used Chapter 5 for primary installation
    1. Run kinit admin - this allows you to use the command line tools otherwise they’ll complain about kerberos.
  5. Log into FreeIPA server at https://<your_hostname>. In my case, Windows popped up a username and password prompt. That prompt didn’t work - I had to exit it and then log into the webGUI.
  6. Go to Users and then directory services in OpenManage. I used the following:
    1. Note: You can get the Bind DN by running ldapsearch from the command line.
  7. Create a new user and new group in the UI and assign the new user to the new group.
  8. Install OpenManage
  9. Go to Application Settings -> Directory Services
  10. Substitute with your values and then click test. I wasn’t able to get this to work with the generic admin user. In the test screen I used that new user to connect to directory services

Further Explanation

Section titled “Further Explanation”

The URI endpoint is: https://192.168.1.93/core/api/Console/import-groups

This is the JSON returned from the call.

The errors occurs at: M.send(y(u) ? null : u)

See here for a description of Javascript’s ternary operator.

In this case it is saying if y(u) is true then the value is set to null, otherwise it is set to u. The y function is:

It is just a basic check to see if u is defined or not. M is an instance of XMLHttpRequest. We can see M being called with open M.open(i, s, !0) where i is “POST” and s is “/core/api/Console/import-groups”.

The problem occurs because objectGuid and objectSid are set to null.
